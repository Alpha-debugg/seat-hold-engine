# AI Usage

AI tools were used while working on this assessment, as the assessment allows AI assistance.

**Tool used:** Claude 

**How it was used:**  
Claude was used as a coding assistant during the development of the ticket hold engine. I used it mainly for discussing implementation approaches, understanding concurrency and locking, reviewing code, identifying edge cases, and getting suggestions for test cases and documentation.

**My involvement:**  
I worked through the implementation and reviewed the suggestions against the assessment requirements. I made the final decisions regarding the business rules, concurrency approach, expiration handling, and overall project structure. I also went through the code to understand how the engine, mutex, fake clock, and tests work.

**Testing:**  
The test suite was run after implementation, along with additional checks for concurrency, expiration, and the business-rule edge cases. I reviewed the test results and made sure the implementation matched the requirements.
